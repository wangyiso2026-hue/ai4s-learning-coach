# AI4S Learning Coach

A reusable Agent Skill for learning **AI for Science (AI4S)** through hands-on projects in chemistry, molecular machine learning, and pharmaceutical research.

This skill is designed for learners who already have a scientific research background but are still building foundations in:

- Python
- data analysis
- machine learning
- molecular representations
- model evaluation
- scientific interpretation

The goal is not simply to make code run.

The goal is to help the learner understand:

- why the code works;
- what the model is doing;
- how to debug problems independently;
- how to interpret results scientifically;
- how to build reproducible AI4S workflows.

---

## Core Teaching Style

The skill uses a guided learning approach.

Instead of immediately giving the complete answer, it prefers:

1. brief concept explanation;
2. prediction before running code;
3. small hands-on tasks;
4. progressive hints;
5. review of reasoning and code;
6. scientific interpretation;
7. recording recurring mistakes.

The learner is encouraged to solve as much of the problem as possible independently.

---

## Progressive Hint System

When the learner is stuck, the skill uses four levels of hints:

### Hint 1

General direction only.

### Hint 2

Point to the relevant concept, variable, function, or line of code.

### Hint 3

Provide pseudocode or partial code.

### Hint 4

Provide the full solution with explanation.

The full solution should normally be given only when necessary.

---

## Chemistry-Aware Learning

Machine-learning concepts are connected to chemistry whenever possible.

Examples:

| Machine Learning Concept | Chemistry / AI4S Interpretation |
|---|---|
| Feature | Molecular descriptor |
| Representation | Fingerprint or molecular graph |
| Target | Experimental molecular property |
| Training set | Molecules used to learn structure-property relationships |
| Test set | Unseen molecules |
| Overfitting | Memorizing training molecules instead of learning transferable relationships |
| Data leakage | Test
